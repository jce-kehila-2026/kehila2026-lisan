# هيكلية المزوّدين (LLM Provider Architecture)

الهدف: **أقصى استخدام مجاني + أفضل جودة + أقل استهلاك لكل مفتاح + خدمة بدون انقطاع.**
كل المزوّدين المفعّلين **مجانيون** (لا يوجد مزوّد مدفوع في السلسلة).

---

## النموذج الطبقي (4 طبقات)

```
طالب → ┌─────────────────────────────────────────────────────────────┐
       │ Tier 0 — LOCAL (بدون LLM)            ~90–95% من الطلبات · $0 │
       │   exact cache · canonical cache · semantic cache · router ·  │
       │   gatekeeper · pre-LLM learning layer · scope guard          │
       └─────────────────────────────────────────────────────────────┘
                         │ (فقط ما يحتاج فعلاً نموذجاً: السيناريوهات + أسئلة معقّدة)
                         ▼
       ┌─────────────────────────────────────────────────────────────┐
       │ Tier 1 — GEMINI 2.5 Flash-Lite       أفضل عبري · 4 مفاتيح     │
       │   round-robin على الـ4 مفاتيح؛ عند 429 → المفتاح التالي فوراً │
       └─────────────────────────────────────────────────────────────┘
                         │ (كل مفاتيح Gemini استُنفدت / 429)
                         ▼
       ┌─────────────────────────────────────────────────────────────┐
       │ Tier 2 — GROQ (Llama 3.3 70B)        سريع جداً · حصة منفصلة   │
       └─────────────────────────────────────────────────────────────┘
                         │ (Groq استُنفد / فشل)
                         ▼
       ┌─────────────────────────────────────────────────────────────┐
       │ Tier 3 — CLOUDFLARE Workers AI (Llama-4-Scout) · حصة منفصلة  │
       └─────────────────────────────────────────────────────────────┘
                         │ (كل المزوّدين فشلوا)
                         ▼
                  fallback محلي مهذّب ("يש עומס, נסה שוב")
```

> الكود: `services/chat_provider.py` — `_build_provider_chain()` + `_build_fallback_chain()`
> + `call_provider()` (التدوير، الميزانية، circuit breakers). التوجيه المحلي في
> `services/chat_engine.py`.

## كيف تتحقق الأهداف الأربعة

### 1) أقصى استخدام مجاني
- **4 مفاتيح Gemini من مشاريع مختلفة** = 4× الحصة المجانية، تدوير round-robin.
- **Groq + Cloudflare** حصص مستقلة تماماً عن Gemini وعن بعض → سعة إجمالية ضخمة.
- المزوّدون الاحتياطيون (Tier 2/3) **يمتصّون الفائض تلقائياً** أيام الذروة لمّا Gemini يوصل 429.

### 2) أفضل جودة
- **Gemini أولاً دائماً** — أقوى عبري ومضبوط على المنهج. الأضعف عبرياً (Llama) احتياط فقط.
- **thinking معطّل** على Gemini flash → الإجابة كاملة غير مبتورة (راجع
  [[gemini-thinking-truncation]]).
- حُرّاس الإخراج (عبري فقط، طول مناسب للمستوى) تنطبق على رد كل مزوّد.

### 3) أقل استهلاك لكل مفتاح
- **Tier 0 محلي** يخدم ~90–95% بدون أي LLM (تقرير الـleakage: 0% LLM للشات العادي).
- **3 طبقات cache** (exact / canonical phrasing-invariant / semantic) تمنع تكرار النداء.
- **round-robin** يوزّع حمل Gemini على الـ4 مفاتيح بالتساوي (مش مفتاح واحد يحترق).
- **max_output_tokens قصير + thinking off** → توكنات أقل لكل نداء.

### 4) خدمة بدون انقطاع
- **3 طبقات احتياط مجانية** متسلسلة؛ لازم تفشل الثلاثة معاً حتى ينقطع.
- **429/quota لا يفتح الـcircuit** — ينتقل فوراً للمفتاح/المزوّد التالي (لا تعطيل متسلسل).
- **circuit breaker لكل مزوّد** يعزل المزوّد المعطوب 60 ثانية ثم يتعافى.
- **ميzانية إجمالية 10 ثوانٍ** (`PROVIDER_TOTAL_BUDGET_SECONDS`) تمنع تراكم المهلات.

## الإعدادات (`.env`) — كلها مضبوطة حالياً ✅

```env
# Tier 1 — Gemini (4 مفاتيح، مشاريع مختلفة، تدوير + failover على 429)
GEMINI_API_KEYS=key1,key2,key3,key4
LLM_PROVIDER=gemini
LLM_MODEL=gemini-2.5-flash-lite

# Tier 2 — Groq (احتياط سريع)
GROQ_API_KEY=gsk_...
GROQ_MODEL=llama-3.3-70b-versatile
GROQ_TIMEOUT_SECONDS=8.0

# Tier 3 — Cloudflare Workers AI (احتياط أخير)
CLOUDFLARE_API_TOKEN=cfut_...
CLOUDFLARE_ACCOUNT_ID=...
CLOUDFLARE_AI_MODEL=@cf/meta/llama-4-scout-17b-16e-instruct
CLOUDFLARE_AI_TIMEOUT_SECONDS=8.0

# (Anthropic غير مضبوط عمداً — مدفوع. تركه فارغاً يبقي السلسلة مجانية 100%.)
```

السلسلة تتفعّل تلقائياً: أي مزوّد يُضاف فقط إذا كان مفتاحه موجوداً في `.env`.

## المراقبة والتحقق

- **probe حي لكل المزوّدين**: `python evals/probe_providers.py`
  (آخر تشغيل: gemini ✅ groq ✅ cloudflare ✅ — كلهم يردّون بعبري سليم).
- **سجلّ المزوّدين**: `GET /api/ai/logs?status=failed` يبيّن أي مزوّد فشل ولماذا.
- **أي مزوّد خدم الطلب**: حقل `provider` في رد `/api/ai/chat`.
- **مسارات الطلب** (محلي/cache/LLM): `GET /api/ai/analytics` → `request_paths`
  و `evals/run_leakage_report.py`.
- **جاهزية**: `GET /api/ai/ready`.

## ملاحظات للإنتاج (1000 طالب)

- التكلفة المتوقعة ضمن المجاني عملياً صفر طالما الحصص المجمّعة تكفي؛ راجع تقدير
  ~$20/شهر فقط لو تجاوزت الحصص المجانية (أدوار السيناريو هي وحدها التي تستهلك LLM).
- **تأكّد أن مفاتيح Gemini الأربعة من 4 مشاريع Google مختلفة** — وإلا تتشارك الحصة
  ولا تتضاعف فعلياً.
- لرفع الجودة لاحقاً دون كسر المجانية: جرّب ترقية Tier 1 إلى `gemini-2.5-flash`
  (حصة منفصلة، عبري أقوى قليلاً) واختبره على `evals/run_scenario_conversations*.py`.
