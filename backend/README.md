# Lisan Backend

Backend foundation for the Lisan project – Sprint 1.

This service provides basic API endpoints using Express with mock data. It is designed to support frontend development without dependency on real backend logic.

---

## 🧱 Tech Stack

- Node.js (v18+)
- Express
- Firebase Admin SDK (initialized only)
- CORS
- Morgan
- dotenv
